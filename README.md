The site provides a brief overview of current research projects and methodological work involving large scientific datasets across multiple domains.

## Research Focus

Research centers on statistical diagnostics, uncertainty auditing, and validation of large-scale scientific inference pipelines.

Across domains, these projects study how aggregated or compressed observables can appear stable while diverging when conditioned on latent variables tied to the data-generation process.

## Active Areas

Current work includes:

- Annotation drift and pathway enrichment sensitivity in GWAS analyses  
- Systematic error diagnostics in large astronomical surveys  
- Background-dependent evaluation of machine learning classifiers in astrophysical imaging  
- Identifiability limits in reduced collider observables using CMS Open Data  
- Reanalysis of public datasets using reproducible statistical pipelines
